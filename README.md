# glibre

C++23/26 no-code game engine. macOS-first (macOS 26 / Apple Silicon
baseline for Metal 4). Plugin-based. SDL3 + Metal 4 (via metal-cpp) +
HLSL (DXC + metal-shaderconverter).

See:

- [PHILOSOPHY.md](PHILOSOPHY.md) — design principles (SOLID, SRP, scope)
- [ROADMAP.md](ROADMAP.md) — short / mid / long-term path
- [GLOSSARY.md](GLOSSARY.md) — ubiquitous language
- [plans/](plans/) — phase implementation plans (link to GitHub issues)
- [specs/](specs/) — bounded-context specs (public interface, invariants)
- [reviews/](reviews/) — review-iteration artifacts

User stories and tasks live in **GitHub Issues**, not in this repo. See
`plans/*.md` for issue references.

Status: pre-implementation. Specs + stories + 3 review iterations gate
any code.
