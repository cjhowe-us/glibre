# Plans

Plans are **GitHub Issues**. Files in this directory are index
pointers, not plan content.

| File | Horizon | GitHub label |
|------|---------|--------------|
| [`mvp.md`](mvp.md) | Short term — MVP | `phase:mvp` |
| [`post-mvp.md`](post-mvp.md) | Mid term — Post-MVP | `phase:post-mvp` |
| [`long-term.md`](long-term.md) | Long term — Harmonius parity | `phase:long-term` |

Each file lists the **initiative** issue for its horizon and points at
the live filter URL. To see actual plan content, follow the links to
GitHub.

## Authoring rules

- No plan content in this repo. Issue bodies and comments are the
  source of truth.
- These index files only carry: initiative number, filter URL, short
  one-liner.
- Story / plan / spike content is NEVER duplicated here. Update the
  GitHub issue instead.
- If a horizon's contexts or initiative number changes, update the
  pointer here in the same PR.
